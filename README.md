# 🍳 Recipe Finder

Recipe Finder is a simple, responsive, and interactive web application that helps users discover recipes from around the world. The application uses the **TheMealDB API** to fetch recipe data in real time and display detailed information in a clean and user-friendly interface.

Users can search for recipes using keywords such as *chicken, biryani,* or *carrot*. The application also includes a **Random Recipe Generator** for users who want to discover new meal ideas instantly.

## ✨ Features

* 🔍 Search recipes by name or keyword
* 🎲 Generate a random recipe
* 📋 View ingredients and measurements
* 👨‍🍳 Read detailed cooking instructions
* 🌍 View recipe category and area of origin
* 🎥 Access YouTube video tutorials
* 📱 Responsive design for mobile and desktop
* ⚡ Real-time API data fetching
* ❌ Error and empty search handling
* 🖼️ Lazy image loading

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* TheMealDB API

This project demonstrates important frontend development concepts such as **API integration, asynchronous JavaScript, Fetch API, Promises, DOM manipulation, responsive design, and modular coding practices**.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Run the `index.html` file in any modern web browser.
4. Search for your favorite recipe and start exploring!
